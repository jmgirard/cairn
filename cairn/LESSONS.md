# Lessons

Durable repo lessons — build quirks, testing tricks, gotchas worth
remembering next time — captured at milestone end and surfaced at plan time.
Not status, not decisions: a lesson is a reusable "how this repo actually
behaves" note. Cross-cutting *choices* still go to `DECISIONS.md`.

One line per lesson: `- YYYY-MM-DD (M<NN>): <lesson>`. Two caps
(tracking-rules weight-caps): 50 lines and 20,000 bytes, met by retiring or pruning entries.
Current knowledge: a lesson proven false is corrected in place (D-045).
Lessons also *leave*: one retires when a test fails on the mistake it warns
about, when another file's slot owns its content, or when a matured family
graduates whole into a doctrine module; pruning the stalest is the last resort
rather than the first (D-051, D-055).

- 2026-07-16 (M56+M65, consolidated M78/M83/M111/M124, extended M121/M137/M138/M140, corrected M144, trimmed M147): "green" is only as wide as what you ran — run each gating suite from the repo root and check each exit code explicitly, never piping (`| tail` is exit-blind) or `;`-chaining a commit past a red check; scope a verification command to the tree that holds the claim, and write git pathspecs out (wildmatch `*` crosses `/`, and unquoted the shell binds it to the working tree); probe a sweep instrument against a known-positive hit before believing an empty result (a decorating flag like `grep -n` re-alphabets later stages; `unittest -k` takes substrings, never pytest `or`, and NO TESTS RAN reads like a red gate); and a probe that mutates or restores files commits pending fixes first, restores in a `finally:`, and re-verifies the fix on disk after the run; and `cairn_validate` green is NOT the gating suites green — any edit under `scripts/` or `hooks/`, or to `skills/shared/templates/` or a `skills/*/SKILL.md` (files the gating tests read), runs both gating suites, trivial tier or not.
- 2026-07-18 (M71, corrected M75, consolidated M92, trimmed M147): hooks trap on MATCHING and on SHIPPING — a `matcher` containing only `[a-zA-Z0-9_|, -]` is a LITERAL split on `|`/`,` (only a metacharacter reaches `new RegExp`, and that path is unanchored; full dispatch: `references/claude-code-hooks.md`), and a new hook ships four surfaces beyond its script: `hooks.json`, BOTH `TestNonCairnNoOp` payload collections in `hooks/tests/test_hooks.py`, `cairn/DESIGN.md`'s inventory bullet (count words included), and `test_positioning_guard.py`'s hardcoded `HOOKS` tuple.
- 2026-07-18 (M72, extends M33, trimmed M92/M98): the merge guard is direction-blind — `git merge main` INTO a feature branch is denied though tracking-rules prescribes merging when main moves, so sync a feature branch with `git rebase main` instead.
- 2026-07-18 (M73): `gh pr create`/`ready`/`merge` all use GraphQL, whose quota can be exhausted while REST is healthy — `gh api repos/{owner}/{repo}/pulls --input <json>` opens a PR (draft included) when `gh pr create` is rate-limited. Never route the MERGE through REST to dodge a limit: merge_guard is a PreToolUse hook matching the merge commands, so a REST merge silently bypasses the approval marker — the enforcement boundary M72 documented.
- 2026-07-18 (M81/M91, trimmed M98): re-dating a DERIVED references page restarts its 180-day staleness clock though half its inputs were never re-read — age a synthesis note from its OLDEST un-re-read input (F4/88).
- 2026-07-19 (M90, trimmed M147): `Edit` with `replace_all` applies ONE fixed indentation to every match — in Python that silently changes block structure and stays valid (a dedented nested loop ran once after its parent, green); never `replace_all` a line whose correct indentation differs between occurrences, and prove a guard reddens for EACH input it covers.

- 2026-07-20 (M99): rewriting an instruction from "transform X into Y" to "author a fresh Y" silently drops X's disposal — step 9 said "compress the milestone file and move it", where the move deleted the live copy implicitly; authoring from a template made the summary a NEW file and nothing removed the old one, orphaning it until `cairn_validate` caught it (F4/85). - 2026-07-23 (M109): a `unittest` skip can't be asserted directly — `skipTest` raises, it doesn't return — so a machine-coupled live test whose skip path must be proven on any machine factors the skip decision into a helper that raises `SkipTest`, then a second test does `assertRaises(SkipTest)` against a synthetic empty input.
