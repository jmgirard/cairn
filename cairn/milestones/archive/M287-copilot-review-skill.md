# M287: A /copilot-review skill handles Copilot's notes on a PR and replies to its summary

**Status:** done (2026-10-19, PR #299 https://github.com/jmgirard/cairn/pull/299)

**Goal:** A user can run `/copilot-review` on any PR to have Copilot's notes read, settled, replied to, resolved, and its summary answered, and the Copilot round in `/hotfix` and `/milestone-review` answers the summary the same way.

**Outcome:** New `skills/copilot-review/SKILL.md` runs outside a milestone run, in repos with or without `cairn/`, and needs no opt-in line. It finds the PR (argument, or `gh pr list --head` for the current branch, with `--repo <base-repo>` on every `gh pr` call), checks out the head, runs the module's state query, wait, and paged reads, then gives each note a disposition. It asks the user in chat about a note it cannot settle, with no question on GitHub. It commits fixes, staging only their files, pushes by the open-PR head rule, replies on and resolves each thread, and posts the summary reply last. It makes no Copilot request and fences the request command on `none`. `skills/shared/copilot-review.md` §5 gains the summary reply: one `gh pr comment` per Copilot review with a non-empty body, once the threads its body anchors are resolved, with the review URL first and one line per thread and body item. A review an operator comment already links is skipped, along with its body items. In `/hotfix` and `/milestone-review`, a note the agent cannot settle takes the follow-up disposition, named at the chip, unless it takes the return floor. No reply thanks Copilot. The skill is listed in band.ts, fixtures.gen.ts, `cairn_cost.PHASES`, README, the rulebook's outside-the-run list, DESIGN (× 11), and CHANGELOG.

**Decisions:** D-187 (summary reply, unsettled notes to chat or follow-up, no request from the skill; annotates D-153). D-188 (module budget reset to under 165 lines and 9,600 bytes).
