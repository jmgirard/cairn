# M328: Wait for CI without stopping the session

**Status:** done (2026-10-31, PR #342 https://github.com/jmgirard/cairn/pull/342)

**Goal:** A merge's CI wait arms a background watch and ends the turn, and the session resumes by itself when CI ends, so the user no longer reruns the skill after a long CI run.

**Outcome:** The wait rule in tracking-rules ("Waiting on CI and background work") and the merge waits of `/milestone-review` step 8 (with its companion arm) and `/hotfix` step 6 now read `gh pr checks` first. While a check is pending, they arm `gh pr checks <N> --watch --fail-fast` as a `run_in_background` task that echoes a wake line (PR, the watch's status, the resume command), then end the turn with a close block fencing that command. At the notification the session acts only on the branch it armed from with a clean tree. It reads `state,headRefOid,latestReviews` and stops on a moved head (review: the head read after step 8's push; hotfix: the marker's oid), a `CHANGES_REQUESTED` review, or a failed read. A failed check takes the red path, a pending one re-arms, and all passed (skipped counted as passed) merges. A typed resume `TaskStop`s the armed watch, and a wake line the session did not arm is shown and run nothing. The armed merge watch is the one exception to the turn-end stop-point bar and to the early-stop clause. A user-enabled host PR monitor (desktop Auto-fix) is the one exception to one watcher per wait, and cairn never turns it on. The watch has no time bound (DESIGN Known issue). `wait-mechanisms.md` gains W24–W26 from a live probe in a recreated private `jmgirard/cairn-wait-lab`: an idle desktop session woken by a late red run and a 12-minute green run, the watch's status only in the wake line. `test_wait_rule` pins the new clauses (mutation-registered), the rulebook baseline is re-seeded (890 lines / 88,178 bytes), and README and CHANGELOG describe it.

**Decisions:** D-229 (arm and wake; supersedes D-128's foreground CI clause and turn-end bar), D-230 (read first, guards, a `perl` alarm bound), D-231 (bound removed after `gh` was found to ignore SIGALRM; moved-head and changes-requested stops), D-232 (`latestReviews`, the recorded head).
