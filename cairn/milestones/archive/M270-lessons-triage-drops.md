# M270: Let /cairn-triage lessons drop false, obsolete, and low-value lessons

**Status:** done (2026-10-17, PR #282 https://github.com/jmgirard/cairn/pull/282)

**Goal:** `/cairn-triage lessons` can free room in a full `cairn/LESSONS.md` by dropping or correcting false, obsolete, and low-value lessons and by shortening long lessons near the caps.

**Outcome:** The lessons pass of `skills/cairn-triage/SKILL.md` has six dispositions. A `drop` names one of five exits: enforcement, ownership, `refuted` (evidence read in the pass shows the premise false), `obsolete` (a read shows the repo no longer has the path, tool, or command, or a commit removed it), and `planner test` (a planner loses nothing, and no tracking file holds the lesson). `correct` rewrites a false lesson that still holds a useful part, with quoted evidence, the line shown at the gate, and a `corrected YYYY-MM-DD` mark. Each other `keep` names what a planner loses. At 45 lines or 18,000 bytes, each lesson over 400 bytes is proposed for `compress` or kept with a reason per clause. The chip warns when the standing proposals leave the file at or over those figures, in every Amend round. A false lesson kept for a pin or a live milestone is named in the stamp. Guest reads use `git cat-file -e` at the base ref, and `cairn/` paths are read on disk. The rulebook's "Retiring a lesson" bullet scopes its three exits to review hygiene and names the pass's three drop exits. README and CHANGELOG follow. `test_triage_lessons.py` and the mutation registry pin each rule. The rulebook-size seed is 719 lines / 69,644 bytes at all three sites. A read-only dry run on this repo's file (47 lines, 19,892 bytes) found 1 `correct`, 1 `planner test` and 1 ownership candidate, and 4 lessons over 1,000 bytes to shorten.
