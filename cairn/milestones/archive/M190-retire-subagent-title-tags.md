# M190: Retire the subagent model-tier title tags

**Status:** done (2026-09-29, PR #197 https://github.com/jmgirard/cairn/pull/197)

**Goal:** Drop the rule that every subagent title opens with a one-letter model tag, because the Claude desktop app now shows each subagent's model.

**Outcome:** `tracking-rules.md` loses the "Subagent titles carry the model tier" bullet. It gains "Set the model on every spawn" under "Model and agent strategy": the session passes the role's model as the Agent tool's `model` setting, Explore fan-outs included. A spawn that sets none takes the agent type's or the harness's default. Every skill site that used a bracket tag now names the model in words. The sites are in plan steps 2 and 3, brief step 3 and its binding-criteria audit, implement step 5 and its amendment and claim audits, the review routing and lens list, the triage delegation note, and the design-interview investigation. The review lens bullets open with the role name ("Diff-bug reviewer (Opus)"). One ROADMAP candidate row was reworded. The `skills/tests` guards for fresh-context readers, the mutation harness, and the review fan-out are re-pinned to the new wording. The fan-out guard's stale scorer docstring was rewritten, and its test is now `test_new_lens_defers_to_gate_triage`. The milestone file was renamed from `-tier-tags` to `-title-tags` so that AC1's grep did not match its own path. CHANGELOG Unreleased entry added.

**Decisions:** D-141 retires the tags, names each model in words, and sets the model on each spawn. D-142 supersedes two of D-141's context clauses: the unset-spawn default, and the app-display fact as the user's report. The work log records two plan-gate choices. Model names plus a set-the-model line won over names alone (falsified by a harness whose Agent tool has no model setting). The `/milestone` rulebook-mass baseline stayed at M166 (falsified by an audit reader misreading the growth figure).

**Review:** The implement-time claim audit read 12 claims and corrected 3. AC1–AC4 were verified in one pass, with no returns. The three-lens fan-out ran because the tier is user-facing. Opus diff-bug found 10, Sonnet blame-history 6 (no past intent undone), and Sonnet prior-review 3 (PR-comment probe empty), 14 after merging duplicates. Eight were rejected with reasons. They were no guard for the new bullet, the fork case, D-142's heading wording, and the lens-regex capitalization. The others were the Sonnet/Opus repetition that predates M190, the unseeded mass baseline, an unconfirmed harness run, and the out-of-scope reference ledgers.
