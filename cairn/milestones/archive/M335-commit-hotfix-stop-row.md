# M335: Commit the row a hotfix stop writes

**Status:** done (2026-11-05, PR #350 https://github.com/jmgirard/cairn/pull/350)

**Goal:** In owner mode, a candidate row that a `/hotfix` step 1 stop writes reaches the default branch in a docs-only commit before the close block, or the close block carries the row and says why it could not.

**Outcome:** `skills/hotfix/SKILL.md` step 1 gains the **Row at a stop** paragraph, which the over-the-bar route (the owner arm's withdrawn approval included), the open-PR cap stop, and the merged-PR re-entry's decline take. It commits only on the default branch, with `cairn/ROADMAP.md` clean and the checkout level after a pull, by a pathspec commit that leaves other uncommitted paths alone. On a failed check, fetch, pull, add, or commit the stop leaves no uncommitted row, and the close block shows the row, names what failed, and fences `/hotfix`. A rejected push is never forced, and the close block names the undo `git reset --keep HEAD~1`. With no remote the commit stays local. A stop with no next command of its own fences `/milestone-plan` with the row's short title. A merged PR over the bar gets its row from step 7's one commit. The rulebook's cap sentence now says "pushes no work branch", and its dirty-tree bullet names the row commit as an exception. README's cap text and the CHANGELOG follow. Guest mode is unchanged.
