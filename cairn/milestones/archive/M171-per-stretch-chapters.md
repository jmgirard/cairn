**Status:** done (2026-09-02, PR #174 https://github.com/jmgirard/cairn/pull/174)

**Goal:** Make the navigable TOC useful in a session that holds one phase: chapters mark the stretches inside a phase (tasks, criteria, gate steps), and the H1/H2 phase header re-emits at every session start.

**Outcome:** tracking-rules "Chapter markers (per-stretch mandate)" — a chapter at each phase transition and at each stretch boundary the active skill's `Chapter markers:` directive names, session start implicit, titles opening with `Tn:`/`ACn:` for a task or criterion and a short noun phrase otherwise; the "Phase header" bullet has the `#`/`##` pair emitted at each session start, a post-`/clear` session included.
